À propos de ce portfolio

Ce portfolio retrace mon évolution de développeur web et mobile vers la cybersécurité. Il regroupe mes expériences en DSI, les projets réalisés pendant mes études et mes premiers travaux en analyse de sécurité et en protection des systèmes d’information.

Objectif

  • Accompagner ma recherche d’un stage de fin d’études en cybersécurité (20 semaines minimum, à partir de mars 2027).
  • Montrer mes compétences en sécurité des SI et en développement web et mobile.
  • Documenter mes projets, de l’assistant RAG cybersécurité (MITRE ATT&CK + NVD) aux applications web en PHP, Vue.js et Django.

Domaines couverts

  • Cybersécurité : veille sur les vulnérabilités (CVE, MITRE ATT&CK), analyse de vulnérabilités d’applications, challenges de type Crackme.
  • Développement web : applications responsives en HTML, CSS, JavaScript, Vue.js et PHP.
  • Développement mobile : jeux et applications en Flutter.
  • Bases de données : MySQL et MongoDB pour le stockage et la gestion des données.

Choix techniques

Le site est codé à la main, sans générateur ni framework JavaScript, pour garder la maîtrise complète du code.

  • HTML et CSS : structure et style des pages.
  • Bootstrap 5 : mise en page responsive, onglets, fenêtres modales.
  • JavaScript : barre de navigation et pied de page communs, galerie de captures.
  • GitHub Pages : hébergement.

Sécurité du site

Même pour un site statique, j’applique les bonnes pratiques que je défends :

  • Politique de sécurité du contenu (CSP) : seuls mes propres fichiers et le CDN jsDelivr peuvent fournir du code, et aucun script n’est écrit directement dans les pages.
  • Intégrité des sous-ressources (SRI) : le navigateur vérifie l’empreinte de Bootstrap et de Font Awesome avant de les exécuter.
  • Liens externes ouverts avec rel="noopener noreferrer".
  • Données personnelles limitées : contact par formulaire, téléphone et adresse e-mail uniquement dans le CV.
